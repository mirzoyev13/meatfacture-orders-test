Архитектурные решения
Redis для антидубликации пушей - для хорошей скорости и безопасности
Laravel Queues для привязки карт и возвратов
Eloquent + миграции + сидеры
Использованы классы и Jobs для бизнес-логики


Задача 1: Обновление дат рождения
POST /api/birthdays
Принимает JSON с user_id => birthdate, обновляет данные
Валидация формата и исключение будущих дат
Логирование ошибок

Задача 2: Дедупликация пушей
Используется Redis и Cache::add
Хеширование user_id + message на 24 часа
Исключает повторные пуши

Задача 3: Привязка карты
Очередь с Job CardJob
Повторы при 502/504 (макс. 3), задержка: 1s → 2s → 4s
Логирование всех состояний

Задача 4: Возврат средств
Эндпоинт /api/orders/{order}/cancel
Автоматический возврат через Job RefundMoneyJob
Интеграция с фейковым платёжным шлюзом
Логирование + уведомления(приходят на почту)

Не забудьте запустить очередь и redis
